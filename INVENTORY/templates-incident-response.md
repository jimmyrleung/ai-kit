# Incident-Response Templates Inventory

Input template for the incident response workflow.

| File                 | Purpose                                                                                                                                                                       |
| -------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `incident-report.md` | Incident report shell — incident ID (`inc_YYYY-MM-DD_descriptor`), severity, timeline, impact. Populated by `/start-incident`; consumed by `/diagnose` and downstream phases. |
